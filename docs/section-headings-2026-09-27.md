# «Название раздела» и «Раздел» — 27.09.2026

Оба элемента доступны в категории «Базовые». «Раздел» — панель с вложенными
вопросами. «Название раздела» (`sectiontitle`) — отдельный редактируемый заголовок
без поля ответа, обязательности или вычисляемого значения.

Заголовок относится к следующим элементам до следующего заголовка **в той же
странице или панели**. Панель после заголовка становится его подразделом.
Заголовок внутри панели действует только внутри неё. Следующая страница начинает
свою иерархию. Одинаковые названия не объединяют разные разделы.

Например, «Название раздела: Сведения» → «Раздел: Контакты» →
«Название раздела: Телефоны» → вопрос «Рабочий» дают путь
`Сведения / Контакты / Телефоны / Рабочий`.

Таблица и HTML выделяют заголовки как структурные столбцы. В XLSX и печати
заполненные группы образуют уровни шапки без лишних столбцов ответов; пустые
группы сохраняют отдельный заголовок. Статистика показывает путь разделов у
вопроса и не считает заголовок ответом. В динамической панели такое же правило
действует внутри каждой записи, в том числе при заполнении DOCX/XLSX по макету.
В списке полей макета показан путь групп; сами заголовки не предлагаются как поля
ответов. Исходные ответы и имена вопросов не изменяются.

Тип зарегистрирован через [официальный API специализированных вопросов SurveyJS](https://surveyjs.io/form-library/documentation/customize-question-types/create-specialized-question-types).
Он использует пустое выражение для отображения редактируемого заголовка;
настройки вычислений и обязательности в конструкторе недоступны.

В бежевой теме внешний фон превью шаблона и ответа теперь белый. Тема самой
формы сохраняется. На время открытия превью отключаются прокрутка основной
страницы и резерв её полосы прокрутки; внутри превью прокрутка работает.

Для публикации нужны сборка frontend и обновление Office service. Новые
миграции базы данных для этих изменений не требуются.
