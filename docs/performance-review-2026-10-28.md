`statement_timeout=90s` ограничивает отдельный SQL-запрос, а не суммарное время транзакции с ожиданием HTTP/worker. Поэтому исходная проблема с удержанием соединений была серьёзнее указанного в замечании ограничения «до 90 секунд».

## Измерение сборки

Исходная версия собрана отдельно из Git с теми же установленными frontend-зависимостями и настройками окружения. Размеры получены из Vite manifest по всему дереву статических импортов; это объём файлов, а не измерение времени загрузки по сети.

| Метрика | До | После |
| --- | ---: | ---: |
| Начальные JS/CSS, байт | 840 496 | 754 830 |
| Начальные JS/CSS, gzip, байт | 222 166 | 197 221 |
| Все файлы dist, байт | 7 350 524 | 7 363 071 |
| Количество файлов dist | 67 | 86 |

Стартовая загрузка уменьшилась на 83,7 КиБ (10,2%), gzip — на 24,4 КиБ (11,2%). Общий размер dist вырос на 12,3 КиБ из-за новых общих чанков, записей манифеста и изменений кода. Общий бюджет увеличен на 16 КиБ; ограничения стартовой загрузки и зависимостей сохранены. Добавлены проверки статических зависимостей TemplatesPage и SurveyPage.

## Проверки и границы

- Frontend: 645 unit-тестов проходят; TypeScript, ESLint, production build, bundle budget и 11 tooling-тестов также проходят.
- Office: 37 тестов проходят, один интеграционный тест пропущен без `OFFICE_TEST_DATABASE_URL` изолированной БД. Новые проверки callback используют подменённые БД/HTTP/Storage и настоящий worker проверки DOCX.
- Mail-worker: 21 тест проходит, включая локальный SMTP-сервер. Зависимости локально переустановлены через npm ci по существующему lockfile; версии и lockfile не менялись.
- Chromium: 16 сценариев — загрузка шаблонов/публичной формы, возврат из превью, Office-диалог и polling, Realtime, печать, персональные ссылки и редактирование ответов. API в этих сценариях подменены фикстурами.

Реальные PostgreSQL, Document Server, Storage и внешний SMTP совместно под нагрузкой не проверялись. Развёртывание в production в эту работу не входило.
