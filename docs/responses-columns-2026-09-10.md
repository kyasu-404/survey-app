# Столбцы ответов: повторяющиеся названия вопросов, 10.09.2026

В форме «ИБ школы» (`77304035-236c-4b2d-bda5-78ee6788adc5`) найдено 16 разных вопросов с заголовком
«КОММЕНТАРИИ. Если не выполнено, то почему?». Внутренние имена всех вопросов уникальны.
Чтение рабочей БД подтвердило наличие отдельных ключей комментариев в сохранённых ответах:
16, 10 и 11 заполненных полей в трёх ответах на момент проверки. Значения ответов не выгружались
для диагностики: проверялись схема и наличие ключей.

Причина: `formatResponsesForTable` записывал значения в объект по заголовку вопроса. Последний
одноимённый вопрос перезаписывал предыдущие, включая перезапись заполненного значения пустым.
Этот объект использовали таблица, HTML и XLSX.

Теперь таблица содержит отдельный упорядоченный список столбцов и строки с ключами на основе
внутренних имён. Заголовки могут совпадать и остаются такими, как их задал автор. Дата ответа
имеет отдельный служебный ключ и признак форматирования. Порядок задаёт схема, а дополнительные
ключи старых ответов добавляются после неё и не перекрывают другие столбцы. Пустые поля сохраняются.
HTML и Excel используют те же ключи и порядок.

Статические панели обходятся как группы; HTML и картинки не создают пустых столбцов ответов.
Матрицы и динамические панели сохраняют составное значение в своём столбце; вложенные объекты
отображаются JSON вместо `[object Object]`.

## Установка

Релиз: `responses-columns-20260910T113003Z`. Production-сборка использует настройки API с `stss`:
`https://api.forms.imc-mosk.ru`; идентификатор сборки `responses-columns-20260910`.

- `stss`: изменённые исходники и тесты применены в `/opt/survey-app`; проверены SHA-256.
- `magi`: сборка установлена в `/var/www/forms.imc-mosk.ru/dist`, HTML заменён атомарно после
  ресурсов. Старые ресурсы с хешами сохранены для открытых вкладок.
- После установки через HTTPS проверены 4 маршрута и 43 публичных ресурса: все SHA-256 совпали
  с проверенной сборкой.
- БД и конфигурация Nginx не изменялись.
- Резервные копии на обоих серверах: `/var/backups/survey-app/responses-columns-20260910T113003Z`.
  На `stss`: `source-before.tar.gz` и `change.patch`. На `magi`: `dist-before` и `index-before.html`.

Быстрый откат frontend на `magi`:

```bash
sudo install -o www-data -g www-data -m 644 \
  /var/backups/survey-app/responses-columns-20260910T113003Z/index-before.html \
  /var/www/forms.imc-mosk.ru/dist/index.rollback.html
sudo mv -f /var/www/forms.imc-mosk.ru/dist/index.rollback.html \
  /var/www/forms.imc-mosk.ru/dist/index.html
```

После установки открытым вкладкам нужно обновить страницу, чтобы загрузить новую сборку.
