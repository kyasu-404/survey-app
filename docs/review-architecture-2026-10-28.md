## Применение и оставшиеся ограничения

Для существующей базы используется только новая миграция удаления RPC, после
всех текущих миграций. Повторно применять bootstrap к рабочей базе не следует.
Миграция не меняет данные таблиц и не использует `CASCADE`: неожиданная зависимость
прервёт её. Приложение уже использует новые RPC; перед применением в другом
окружении нужно проверить отдельно развёрнутых старых клиентов. Для отката RPC
нужно восстановить только три удалённых определения и их grants из исходной
версии схемы; повторно выполнять старые миграции целиком не следует.

`!important` и глобальные селекторы сохранены. Их сокращение потребует отдельного
изменения каскада с визуальными проверками SurveyJS. Разбиение файлов устраняет
монолит, но само по себе не устраняет этот оставшийся CSS-долг.
