# Названия страниц и разделов в ответах — 10.09.2026

## Поведение

- Таблица ответов и HTML показывают явные непустые названия страниц и вопросы
  `sectiontitle` в порядке схемы, отдельными столбцами с пустыми ячейками ответов.
  Страницы выделены синим цветом, разделы — жирным заголовком и границей слева.
  Оформление поддерживает светлую и графитовую темы.
- Техническое имя страницы без заголовка не выводится. При переходе на любую
  следующую страницу предыдущий раздел заканчивается, даже если новая страница без названия.
- В Excel над вопросами добавляются строки страниц и разделов с объединениями
  над относящимися к ним вопросами. При наличии обоих типов — три строки заголовков,
  при наличии одного — две, без групп — прежняя одна. Заголовки закреплены при прокрутке.
  Пустые страницы и разделы сохраняются как отдельные пустые столбцы.
- Ключи групп и вопросов независимы от отображаемых названий. Одноимённые страницы,
  разделы и вопросы сохраняются отдельно; старые поля ответов идут после схемы без групп.
  Сохранена защита HTML и XLSX от интерпретации пользовательского текста как кода/формул.
- Для `sectiontitle` скрыто изменение обязательности и на панели вопроса, и в панели
  свойств. Использованы `onElementAllowOperations.allowChangeRequired` и
  `onPropertyShowing.show` из [API SurveyJS](https://surveyjs.io/survey-creator/examples/remove-properties-from-property-grid/documentation).
  Значения по умолчанию из предыдущего релиза сохранены: `sectiontitle` и `expression`
  необязательны; обычные вопросы обязательны. Названия разделов не добавляются в статистику.

Эта логика заменяет исключение `sectiontitle` из таблицы ответов, описанное в
`section-title-2026-09-10.md`.

## Установка

Релиз `grouped-responses-20260910T131453Z`, идентификатор сборки `grouped-responses-20260910`.
Исходники — `stss:/opt/survey-app`, frontend — `magi:/var/www/forms.imc-mosk.ru/dist`.
Перед установкой содержимое затронутых исходников сверяется с предыдущим релизом.
Резервные копии на обоих серверах:
`/var/backups/survey-app/grouped-responses-20260910T131453Z`.

Файлы ресурсов устанавливаются перед атомарной заменой `index.html`, старые хешированные
ресурсы сохраняются. База данных и конфигурация Nginx не меняются.
Для отката frontend на `magi`:

```bash
sudo install -o www-data -g www-data -m 644 \
  /var/backups/survey-app/grouped-responses-20260910T131453Z/index-before.html \
  /var/www/forms.imc-mosk.ru/dist/index.rollback.html
sudo mv -f /var/www/forms.imc-mosk.ru/dist/index.rollback.html \
  /var/www/forms.imc-mosk.ru/dist/index.html
```

На `stss` сохранены `source-before.tar.gz` и инкрементальный `change.patch`.
